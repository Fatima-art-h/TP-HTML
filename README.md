Description du TP : JavaScript
Ce TP a pour objectif de découvrir et de pratiquer les bases du langage JavaScript à travers plusieurs exercices pratiques.

Question 1 : Que représente this dans onfocus="mettreEnEvidence(this)" ?
this représente l'élément HTML qui déclenche l'événement. Dans cet exemple, il représente le champ de saisie du prénom (input). Il permet de transmettre directement cet élément à la fonction pour modifier son style.

Question 2 : Que représente this dans la méthode presenter() lorsqu'elle est appelée par inscription.presenter() ?
this représente l'objet inscription qui appelle la méthode presenter(). Il permet d'accéder aux propriétés de cet objet.
